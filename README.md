# 🧮 BMI Calculator 

## 📌 Project Overview

This project is a **BMI (Body Mass Index) Calculator** developed in Python as part of an internship task.
It allows users to enter their physical details and calculates BMI to determine their health category.

The project is implemented as a **GUI application using Tkinter**, focusing on usability, validation, and basic data analysis.

---

## 🎯 Objectives

* Calculate BMI accurately using the standard formula
* Validate user input and handle errors gracefully
* Provide a clean and user-friendly interface
* Store BMI records for multiple users
* Display BMI trends using a graph

---

## 📐 BMI Formula

```
BMI = weight (kg) / height (meters)²
```

> Height is taken in **meters** as specified in the task instructions.

---

## 🩺 BMI Categories

| BMI Value      | Category    |
| -------------- | ----------- |
| Less than 18.5 | Underweight |
| 18.5 – 24.9    | Normal      |
| 25 – 29.9      | Overweight  |
| 30 or above    | Obese       |
